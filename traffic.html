Cómo funciona y qué se recupera

El workflow consulta los últimos 14 días disponibles en GitHub y combina registros por fecha, sin duplicar días. Solo muestra datos que se hayan podido consultar; no interpreta errores como cero visitas. El historial es privado y requiere autorización. Las métricas de vistas y clones pueden tener retrasos y la API puede devolver días incompletos. Los rankings de referentes y rutas no se conservan como series históricas.
